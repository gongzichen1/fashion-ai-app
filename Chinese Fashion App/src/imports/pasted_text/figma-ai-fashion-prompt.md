# Figma Make Prompt

Create a complete high-fidelity WeChat Mini Program UI design for an AI-powered fashion styling assistant called:

智搭

English name:

StyleMind AI

The product helps users photograph or upload clothing items, uses AI vision analysis to identify clothing attributes, and generates outfit recommendations based on weather, personal style preferences, body type, wardrobe inventory, and usage scenarios.

The design should feel like a premium lifestyle fashion product rather than a utility tool.
