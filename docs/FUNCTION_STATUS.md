## 4. 自动验证覆盖

当前仓库测试能证明的范围：

- Flask 应用可导入；
- 使用伪天气响应时，经纬度错误返回 400，合法请求能生成规则建议；
- 使用伪 AI 时，图片分析、结果读取和历史读取形成基本闭环；
- 无文件扩展名但图片头合法的 PNG 上传可被接受。
- 鉴权资源在退出后返回 401，两个开发账号的收藏数据互不可见且不能互删；
- AI 失败返回 503、明确错误码和 requestId，不生成固定成功；
- 本地后端 33 项通过、2 项真实 MySQL/PostgreSQL 集成测试因无本地服务跳过；新增生产依赖硬校验、COS 在线检查、最后引用删除和双账号验收工具测试。飞书 H5 有 2 项 `ttfile` 转换测试通过。GitHub Actions 上一轮已确认 Python 3.11、两种数据库和 Docker；本轮新增测试待推送复验。

当前测试不能证明的范围：

- 真实 AI 服务、真实 Open-Meteo、CloudBase、托管数据库和对象存储；
- 真实飞书/微信身份、授权码重放、生产 Cookie 和 CSRF；本地双账号隔离已有自动测试；
- 飞书或微信客户端权限行为；
- 并发写、容器重启、图片到期删除和大规模分页；
- UI 在飞书移动端和桌面端的视觉/交互一致性。

当前最没有把握的是线上模型视觉请求的真实成功率。最大的容易遗漏项是“页面存在”并不代表“用户数据已服务端保存并隔离”。
